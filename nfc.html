Patient NFC Card

Write a patient ID to an NFC card or read an existing patient card using the ESP32 and RC522 reader.

Write Patient Card

Select a patient and write their patient ID to the NFC card using ESP32 and RC522.

ESP32 not connected
How it works: Select a patient → connect ESP32 → place the card on RC522 → write the patient ID.

Read Patient Card

Place an NFC card on the RC522 reader and read the patient information.

Ready to read card
Note: The card stores only the patient ID. Complete clinical information is loaded from the database.

Mobile NFC

Use the phone's built-in NFC to write or read patient cards. No ESP32 or RC522 is required.
